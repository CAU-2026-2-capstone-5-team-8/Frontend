# 서점형 앱 개편과 출시 범위 — 2026-10-04

## 실제 변경

- 별도 HTML 시안이 아닌 기존 React Native + Expo 앱에 흰 배경, 상단 메뉴, 모바일 하단 메뉴, 테두리 없는 책 목록과 대표 도서 구성을 적용했다.
- 추천 API는 `concept-learning-v2`를 명시적으로 요청한다. 과거 추천은 재조회할 수 있고 새 추천과 재시도 키는 분리한다. 계정·분야·프로필·능력이 일치하는 저장 결과만 보여준다.
- 책 상세에 읽기 전 살펴볼 개념을 표시한다. 복습할 내용/아직 확인하지 않은 내용/정답으로 확인한 내용을 구분하며, 서버 선수관계 순서와 결과를 임의로 바꾸지 않는다.
- 모델 버전·증거 ID·해시·후보 통계·긴 연구 한계 문단을 사용자 화면에서 제거했다. 오류와 재시도, 공개 후기의 공개 범위 안내는 유지한다.
- 계정 프로필 로딩/오류를 진단이 없는 상태로 잘못 표시하지 않도록 처리했다. 책 상세의 선택적 개념 정보 요청이 실패해도 도서 정보와 서재 기능은 유지한다.
- 검토된 `coverUrl`을 목록·상세·추천·서재에서 사용한다. 표지가 없거나 로딩에 실패해도 책 제목·저자·이동은 남는다. Backend #34는 선택적 필드이므로 이전 서버의 null/필드 부재도 처리한다.
- 배포용 Docker 이미지, 원본 서버 주소 검증, health endpoint, 요청 제한·timeout·인증 전달·deep-link fallback, 실제 서비스 smoke 명령을 추가했다.

## 유지하는 계산 원칙

목차와 수집된 정보는 책과 개념의 연결에 사용한다. 본문이 없는 책에 절대적인 독해 난이도나 설명 깊이 점수를 생성하지 않는다. 같은 도서의 개념 연결과 선수관계는 사용자의 응답 때문에 바뀌지 않는다. 사용자 관찰은 읽기 전 복습/확인 목록과 추천 비교에 사용한다. 자기평가를 객관식 정답이나 숙달 확률로 바꾸지 않는다. 책 내부에 선수가 등장한다는 사실만으로 충분히 설명된다고 보장하지 않는다.

이번 프론트 변경은 ML 순위 계산을 바꾸지 않는다. 정답 한 문항과 미평가를 구분하는 규칙·상태·API 계약 검증이며, 사람 평가에 기반한 추천 정확도 향상 실험은 아니다. 원래 없던 본문·표지·정답·실력 관찰을 만들어 넣지 않는다.

## 검증 자료

- 최종 코드에서 타입 검사·린트와 34개 테스트가 통과했다. Docker 최종 이미지에서도 39개 실제 HTTP 검사가 통과했다.
- 실제 브라우저에서 가입·진단·추천·책 상세·서재 저장을 확인했다. 320/390px에서 가로 넘침이 없고, 320px 책 목록은 2열, 1440px은 5열이다. 모바일 대표 책의 설명과 표지가 겹치던 문제를 수정했다.
- 추천에 표시된 표지 5개의 실제 이미지 로딩을 확인했다. 22개 전체 표지의 시각 검수를 완료했다는 뜻은 아니다.
- 이미 선택한 분야를 다시 누르면 프로필이 사라지던 문제를 재현하고 수정한 뒤, 같은 분야 재선택 시 추천이 유지됨을 확인했다.

- 단위/HTTP 검사는 루트 `npm run check`에 포함한다. 타입 검사·린트·인증 격리·v2 계약·표지 URL·프록시·잘못된 URL 디코딩을 검사한다.
- 잘못된 percent-encoded URL이 기존 decoder에서 제한 시간을 초과하는 문제를 재현했다. 패치된 decoder와 CommonJS 어댑터로 수정 후 한글·중복 키·직렬화·잘못된 입력 테스트가 통과했다. [공식 권고](https://github.com/advisories/GHSA-vcc3-ghjq-m6fr), `native/patches/README.md` 참조.
- 웹 export와 iOS/Android Hermes 번들을 생성한다. 번들은 휴대폰 실기기 테스트 또는 스토어 심사를 뜻하지 않는다.
- 실제 도서 25권을 현재 코드로 처리했다. 개념 연결 7권, 책/개념 연결 59건, 추천 5권이 실제 HTTP에서 확인됐다.
- 실제 서비스 39단계 검사에는 계정·프로필·진단·v2 추천·동일 저장 결과 재조회·서재·후기 CRUD·다른 계정의 403·로그아웃 후 401이 포함된다. 상세 기록은 [전체 검증 기록](release-verification-2026-10-04.md).

## 공개 운영 전 구분할 사항

배포 가능한 웹 코드와 추천 콘텐츠의 충분성은 다르다. 현재 이 PC의 재현 가능한 진단 자료는 사람 검토를 받은 객관식 1문항과 별도로 표시한 로컬 자기평가 8문항이다. 이 로컬 검증 은행을 완성된 운영용 객관식 은행으로 배포하지 않는다. 공개 서비스에 쓸 검토 문항·커버리지와 대상 분야를 확정해야 한다. 기존 승인 파일이 없는 것을 임의 승인으로 채우지 않았다.

운영 계정에는 이메일 인증·비밀번호 재설정이 아직 없다. 현재 범위는 제한된 캡스톤 검증/베타이며, 일반 공개 운영 범위는 이 제약을 고려해야 한다. 카메라·OCR와 대규모 커뮤니티는 이번 출시 범위에 포함하지 않았다.

도메인·HTTPS·운영 데이터베이스·백업·모니터링·접근 정책·비밀값·운영 데이터 import는 배포 담당자가 설정한다. [웹 배포](web-release.md), [전체 서비스 연결](full-stack-release.md)을 따른다. 이번 작업에서 공개 배포나 새로운 PR 자동 머지를 수행하지 않았다.

## 의존성 보안

URL decoder의 런타임 문제는 수정했다. 나머지 npm audit 경고는 빌드 도구의 braces/node-forge/uuid 의존 경로에 남아 있다. 구체적 버전과 제거 조건은 패치 문서를 따른다. 경고를 숨기거나 SDK를 과거 버전으로 강제 다운그레이드하지 않았다. 운영 웹 이미지는 node_modules 없이 정적 export와 Node 기본 모듈 서버만 포함한다. 이는 모든 보안 검토가 끝났다는 뜻은 아니다.
